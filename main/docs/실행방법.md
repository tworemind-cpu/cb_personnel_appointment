# 📥 다운로드 및 실행 방법

[← README로 돌아가기](../README.md)

## 1. 다운로드

**[👉 최신 personnel_appointment.zip 다운로드 (Releases)](https://github.com/tworemind-cpu/personnel_appointment/releases/latest)**

1. 위 링크를 눌러 Releases 페이지로 이동합니다.
2. **Assets** 목록에서 최신 `personnel_appointment.7z` 를 내려받습니다.

## 2. 실행

1. 내려받은 `personnel_appointment.7z` 의 압축을 풉니다.
2. `인사발령정리.xlsx` 파일을 열고 기관현황 시트의 b3셀에서 작업할 지역을 선택한 후 저장하고 종료합니다.
3. `personnel_appointment.exe` 를 **더블클릭**하면 바로 실행됩니다. (별도 설치 필요 없음)
4. 처음 실행할 때 **"Windows의 PC 보호"** 경고창이 뜨면 다음 순서로 진행해 주세요.
   1. 경고창에서 **추가 정보** 를 클릭합니다.
   2. 새로 나타난 **실행** 버튼을 클릭합니다.
> ⚠️ 서명되지 않은 개인 제작 프로그램이라 처음 실행 시 경고가 나올 수 있으며, 위 순서대로 진행하면 정상적으로 실행됩니다.
5. 파일 선택 팝업이 뜨면 도교육청 인사발령 한글 파일을 선택합니다.
6. 접근 허용 팝업은 자동으로 모두 허용을 클릭하도록 설정되어 있으나 10초 정도 경과 후에도 작동하지 않을 경우 직접 모두 허용을 클릭합니다.
7. 자동으로 `인사발령정리.xlsx` 파일을 실행하도록 설정되어 있으나 10초 정도 경과 후에도 열리지 않을 경우 직접 실행합니다.

## 3. 사용 환경

- **Windows 10 / 11** (64비트)
- 한글·엑셀·워드·파워포인트 파일을 PDF로 변환하려면 해당 프로그램이 PC에 설치되어 있어야 합니다. 자세한 내용은 [README의 사용 환경](../README.md#-사용-환경)을 참고해 주세요.
