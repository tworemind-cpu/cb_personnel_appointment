# 📄 인사발령 정리 도우미

### 👉 [📥 다운로드 및 실행 방법](docs/실행방법.md)

도교육청 **인사발령서(hwp, hwpx)** 를 읽어서, 관내 기관의 **전입·전출 현황을 직급·직렬별로 정리한 '전의' 시트**를 엑셀에 자동으로 만들어 주는 Windows용 프로그램입니다.
복잡한 설정 없이, 파일 하나를 고르기만 하면 됩니다.

> 현재 버전: **1.7.0**

---

## 📖 간단 사용법

1. `인사발령정리.xlsx` 파일을 **프로그램(exe)과 같은 폴더**에 둡니다.
   이 파일 안에 **'기관현황' 시트**가 있어야 합니다.
2. 프로그램을 실행하면 나오는 창에서 **도교육청 인사발령서(hwp, hwpx)** 를 선택합니다.
3. 한글이 자동으로 열렸다 닫히며 데이터를 읽어 옵니다. (이때 **키보드와 마우스를 건드리지 마세요.**)
4. 작업이 끝나면 `인사발령정리.xlsx` 에 **'전의' 시트**가 만들어지고 파일이 자동으로 열립니다.

### '기관현황' 시트 작성 방법
| 위치 | 내용 |
|---|---|
| `B3` | 기준 지역명 (예: 관내 지역 이름) |
| `D2` | (선택) 추가로 관내로 볼 특별 기관명 |
| `C3` 열부터 아래로 | **지역 / 임용기관 / 부서** 순서로 목록 입력 |

- 임용기관·부서를 적은 **순서가 곧 정렬 순서**입니다.
- 기준 지역과 같은 지역에 적힌 기관만 '관내'로 인정합니다.

---

## ⚠️ 알아두실 점

- **`인사발령정리.xlsx` 가 엑셀에서 열려 있으면 안 됩니다.** 완전히 닫은 뒤 실행해 주세요.
- 이미 '전의' 시트가 있으면 **지우고 새로 만듭니다.** 필요한 내용은 미리 다른 곳에 복사해 두세요.
- 한글 접근 허용 팝업은 키보드 입력(Alt+N)으로 자동 처리합니다. **실행 중에 다른 창을 누르거나 타자를 치면** 허용이 제대로 안 될 수 있습니다.
- 인사발령서의 **문장 형식이 평소와 크게 다르면** 직급·부서가 잘못 나뉠 수 있습니다. 결과는 **반드시 원본 발령서와 대조**해서 확인하세요.
- 기관현황에 없는 기관은 관내로 인식되지 않습니다. 빠진 사람이 있다면 '기관현황' 시트를 먼저 확인해 보세요.

## ✨ 주요 기능

### 1. 📥 인사발령서 자동 읽기
- 한컴오피스 한글로 `.hwp` / `.hwpx` 인사발령서를 열어 **글자를 자동으로 추출**합니다.
- 한글 파일을 열 때 나오는 **접근 허용 팝업을 자동으로 처리**합니다.
- 추출한 임시 파일은 작업이 끝나면 자동으로 지워집니다.

### 2. 🔍 관내 전입·전출 자동 판별
- `인사발령정리.xlsx` 의 **'기관현황' 시트**에 적어 둔 기관 목록과 대조해, 관내 기관으로 **들어오는 사람(전입)** 과 **나가는 사람(전출)** 을 구분합니다.
- 관내 기관끼리 이동한 경우(자체 전보 등)는 전입·전출 양쪽에 모두 표시합니다.
- 발령 구분을 자동으로 붙여 줍니다.

| 구분 | 예시 |
|---|---|
| 인사 이동 | 승진 · 전보 · 전입 · 전출 · 신규임용 |
| 휴직·복직 | 휴직 · 복직 |
| 파견 | 파견 · 파견복귀 |
| 퇴직 | 명예퇴직 · 정년퇴직 · 퇴직 |
| 기타 | 전문관지정 |

### 3. 🗂 직급·직렬별 그룹 정리 ('전의' 시트)
전입(왼쪽)과 전출(오른쪽)을 **나란히** 놓고, 아래 그룹별로 표를 나눠 만듭니다.

| 그룹 | 직렬 | 세부 구분 |
|---|---|---|
| 1그룹 | 행정 · 전산 · 사서 · 공업 · 보건 · 식품위생 · 시설 | 5급 이상 / 6급 / 7급 이하 |
| 2그룹 | 조리 · 시설관리 · 운전 · 사무운영 | 5급 이상 / 6급 / 7급 이하 |
| 기록연구사 | 기록연구 | - |
| 임기제 | 임기제 공무원 | - |

- 전입자와 전출자가 **모두 없는 그룹은 표시하지 않습니다.** (한쪽만 있으면 빈 쪽에 '해당 없음'으로 표시)
- 직급 명칭을 간단하게 바꿔 줍니다. (예: 지방행정주사 → 행정 6급, 서기관 → 4급)

### 4. 🔢 자동 정렬
각 표는 아래 순서대로 정렬됩니다.

**직급 → 직렬 → 발령 구분 → 부서(기관현황 시트의 순서) → 성명**

### 5. 🖨 인쇄까지 고려한 서식
- A4 **가로** 방향, 한 페이지 너비에 맞춰 인쇄
- 그룹이 잘리지 않도록 **페이지 나누기 자동 설정**
- 제목 행(1~3행)을 모든 페이지에 반복 표시
- 글자 길이에 맞춰 **열 너비 자동 조정**, 표 테두리·머리글 색 자동 적용

### 6. ⏭ 자동으로 제외하는 발령
- **필수실무요원** 발령
- **전문관 해제**만 있는 발령
- **겸임** 발령

### 공통 기능
- 작업이 끝나면 완성된 엑셀 파일이 **자동으로 열립니다.**
- 프로그램 실행 시 **새 버전을 자동 확인**하여 업데이트 안내 (인터넷이 막혀 있으면 조용히 넘어갑니다)

- **Windows 10 / 11** (64비트)
